# Security Policy

## Supported Versions

This project does not aim to provide long-term support or ongoing maintenance for older releases. Support and fixes will generally focus on the latest stable release.

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.**

If you discover a security vulnerability or an exploitable flaw in vigil:

* **Preferred Method:** Use [GitHub Private Vulnerability Reporting](https://github.com/DMsuDev/vigil/security/advisories/new) to submit a confidential report.
* **Minor Concerns:** For non-critical hardening suggestions, low-impact weaknesses, or insecure default settings, feel free to open an **Issue** or start a **Discussion**.

They will be reviewed as soon as possible.
