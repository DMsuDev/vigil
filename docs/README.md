# Vigil Documentation

Vigil is a cross-platform C++ library for logging and diagnostics. These documents go deeper than the [project README](../README.md).

## Where to start

| If you want to...                                    | Read                                                  |
| :--------------------------------------------------- | :---------------------------------------------------- |
| Add Vigil to a project and get it compiling          | [Getting started](getting-started.md)                 |
| Look up a CMake option or preset                     | [Getting started](getting-started.md#cmake-options)   |
| Fix a build or linking problem                       | [Getting started](getting-started.md#troubleshooting) |
| Learn the logging, assertion, or crash handling APIs | [User guide](user-guide.md)                           |
| Understand how Vigil works internally                | [Architecture](architecture.md)                       |
| Build from source, run tests, or send a pull request | [Development](development.md)                         |

## Contents

- [Getting started](getting-started.md): requirements, the three ways to integrate Vigil, CMake options, presets, and troubleshooting.
- [User guide](user-guide.md): every public feature with examples: logging, named loggers, async output, hooks, rate limiting, assertions, scoped logging, stack traces, crash handling, and utilities.
- [Architecture](architecture.md): source layout, layering, threading model, the crash pipeline, the build system, and the reasoning behind decisions that may look wrong at first glance.
- [Development](development.md): building, testing, continuous integration, code style, commit conventions, and the release process.
